A whole story in 31 characters, written by a small program for make.fun's "Tell a Whole Story in 32 Characters" bounty.

> Dad Changed It. Ask Your Mother

Dad changed the Wi-Fi password and won't tell you — go ask your mother. Three characters in two sentences: Dad, Mom, and the kid locked out in the middle, reading the network list. The password itself as leverage in a parental cold war — not a breakup line, not a stock Wi-Fi joke.

## Run it

```sh
node main.ts
```

It writes the name to `output/entry.txt`, exactly 31 characters, deterministic on every run.
